# 法国弹道防护装备展示网站项目书

## 1. 项目概述

本项目旨在搭建一个面向法国及欧洲专业客户的弹道防护装备展示网站。网站主要用于展示公司可对接的防护类产品，包括防弹背心、防弹头盔、防弹盾牌、防弹插板、防弹芯片、软质防护组件、防弹毯及特殊防护方案等。

本项目第一阶段定位为静态产品展示站，不涉及在线下单、购物车、支付系统或用户登录。网站重点在于建立专业、可信、高级的品牌形象，帮助潜在客户了解产品类别、供应链能力、技术资料对接方式以及法国销售管理团队的服务定位。

---

## 2. 项目背景

公司货源主要来自中国供应链，法国团队负责法国及欧洲市场的销售管理、客户沟通、资料对接、订单协调与后续商务跟进。

弹道防护类产品不同于普通消费品，客户通常不会直接在线购买，而是需要先了解产品类型、防护等级、材料结构、应用场景、技术文件、认证资料及报价信息。因此，本网站不采用传统电商模式，而采用 B2B 产品展示与询盘模式。

网站的核心目标不是“在线销售”，而是：

- 展示公司产品范围
- 建立专业可信的企业形象
- 突出法国本地销售管理能力
- 承接客户咨询与技术资料申请
- 为后续法语版本、CDN、表单系统和正式部署预留扩展空间

## 9. 图片资源管理方案

开发阶段图片存放于：

```text
public/images/
```

图片引用方式：

```text
/images/products/vest/警用防弹衣1正.jpg
```

后期迁移 CDN 时，不需要逐页修改图片路径，而是通过统一工具函数处理：

```ts
const CDN_BASE_URL = import.meta.env.VITE_CDN_BASE_URL || ''

export function assetUrl(path: string) {
  if (!path) return ''

  if (path.startsWith('http://') || path.startsWith('https://')) {
    return path
  }

  const base = CDN_BASE_URL.replace(/\/$/, '')
  const normalizedPath = path.startsWith('/') ? path : `/${path}`

  return `${base}${normalizedPath}`
}
```

上线后只需配置：

```env
VITE_CDN_BASE_URL=https://cdn.example.com
```

## 13. 风险与注意事项

### 13.1 图片质量风险

现有 JPG 图片可能存在白底、尺寸不统一、清晰度不一致等问题，会影响网站高级感。后期建议统一处理。

### 13.2 合规措辞风险

弹道防护类产品不应使用过度绝对化表述。

避免使用：

- 100% 防弹
- 绝对安全
- 任何场景适用
- 保证防护
- 军用最高级

建议使用：

- 专业防护场景
- 技术资料按需提供
- 具体等级以正式文件为准
- 面向专业客户
- 资料申请与商务沟通确认

### 13.3 多语言风险

中文文案不能直接逐字翻译为法语。法语版本应更克制、更商务、更符合 B2B 专业语气。

### 13.4 后续维护风险

如果产品数量增加或需要非技术人员维护内容，后续应考虑 Headless CMS 或简单后台管理系统。

## 15. 项目总结

本项目适合采用轻量级静态展示站方案。第一阶段不需要后端，不需要数据库，也不需要购物车。网站应以高级 B2B 展示为核心，突出产品类别、供应链能力、技术资料对接和法国销售管理团队的专业定位。

整体设计方向应避免普通电商风格，而应采用黑色、高级、克制、技术感强的品牌展示风格。后续可在中文版本完成后接入 i18n，实现中法双语切换，并逐步扩展 CDN、表单、SEO 和正式部署能力。
